# kk agent 2

视频分流入口。上传原视频、填写模型接口及规则后，按所选时长模式进入A或B链路。

## 时长模式

- 32秒模式：不足32秒进入A，达到32秒进入B；输出参考视频最长30秒。
- 17秒模式：不足17秒进入A，达到17秒进入B；输出参考视频最长15秒。
- 原视频最长60秒。参考视频截短不改变反推分析范围。

## 输入

- 原视频：需要分析的视频。
- image1—image10：可选参考图，用途写在本次用户要求中。
- 反推密钥、反推AI Base URL、模型名称：供分段、统筹和提示词反推调用。
- 审核密钥、审核AI Base URL、模型名称：供视觉选帧和最终审核调用。
- 本次用户要求与系统提示词：本次需求及A链路规则；B链路使用独立的分段、反推和审核规则。
- 音频1—3：可选的声音参考绑定；原片对白由本地转写生成证据。

## 输出与连接

- video1—video5 → 原生SaveVideo。不存在的分段停止对应分支。
- 反推资料 → kk agent 2独立反推；也连接kk agent 2独立抽帧。
- 入口前三个文本输出是准备阶段信息，最终提示词请从独立反推节点取得。

视频准备好后立即交给保存分支，后台继续AI统筹、选帧、反推和审核。保存目录、格式及编码由保存节点决定。多个原生保存节点仍按ComfyUI调度依次执行。

更新前的图片连线会迁移到独立抽帧节点。若画布仍显示旧端口，请重启ComfyUI、强制刷新网页并重新打开工作流。
