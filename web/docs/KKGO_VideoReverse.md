# kk agent 2 独立反推

接收入口的“反推资料”，等待同一任务的提示词反推与最终审核结果。无需读取SaveVideo生成的视频文件。

## 输入

- 反推资料：连接kk agent 2入口的同名输出。请勿连接文本或视频端口。

## 输出

- 提示词：审核后的最终提示词。
- 分析证据：JSON形式的本地证据、模型阶段记录与耗时。
- 状态：完成说明。
- 分镜参考图列表、抽帧信息、第1—5段参考图：兼容旧流程的最终图片输出，会等待最终审核。

要在最终审核之前保存或编辑图片，请将入口的“反推资料”同时连接“kk agent 2独立抽帧”。两者共享一次任务，不会重复反推。

A链路按完整原片反推；B链路按固定分段范围并行反推，再统一审核。点击ComfyUI停止会取消该任务的模型连接及媒体工具。
