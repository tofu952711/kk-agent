# kk agent 2 完整视频反推

一体执行节点：根据32秒或17秒模式选择A/B链路，完成分析、分段、选帧、反推和审核后统一返回结果。

## 输入

配置与kk agent 2分流入口相同：原视频、可选参考图和音频、反推/审核模型的密钥、Base URL、模型名称、用户要求及A/B链路规则。支持最长60秒原视频。

## 输出

最终提示词、分析证据、状态、video1—video5、全部参考图、抽帧信息及第1—5段参考图。图片为IMAGE列表，可连接原生SaveImage。

## 提前保存视频或图片

一体节点的输出等待整条链路结束。如需保存与AI处理异步进行，使用“kk agent 2”入口，将“反推资料”分别连接“独立反推”和“独立抽帧”，video1—video5连接原生SaveVideo。

32秒模式参考视频最长30秒，17秒模式最长15秒；提示词仍覆盖完整原片或完整分段。旧节点ID保持不变。
