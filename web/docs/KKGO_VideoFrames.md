# kk agent 2 独立抽帧

从同一任务取得已选好的原视频参考图，供保存、编辑以及后续视频生成使用。图片就绪即输出，不等待最终提示词审核。

## 输入

- 反推资料：连接kk agent 2入口的同名输出，同时保留到独立反推节点的连线。

## 输出

- 分镜参考图列表：所有段的图片列表，可直接连接原生SaveImage。
- 抽帧信息：JSON，记录段号、原片时间、段内时间、图片引用编号及选择依据。
- 第1—5段参考图：仅包含对应videoN的图片列表，可分别连接图片处理和保存节点。

B链路每段使用独立选帧会话，复用审核区域的视觉模型配置。A链路没有B分段选帧，图片分支停止，不输出空白图片。

图片编号按每段独立计算：已上传参考图在前，抽帧图在后。编辑后按抽帧信息中的mention编号用于该段视频生成。

本节点不选择保存目录；多个原生图片处理/保存节点之间的执行顺序由ComfyUI决定。
